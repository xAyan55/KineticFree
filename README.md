# KineticHost (KineticFree)

> **Free Forever 24/7 Minecraft Server Hosting Landing Page & Design System**

A modern, high-performance web experience built with Vite, React 18, TypeScript, Tailwind CSS, and shadcn/ui components.

---

## ⚡ Features

- **Hero Landing Section**: High-impact video background hero with instant server creation CTA, glassmorphism floating navbar, and live server stats.
- **Bento Features Grid**: 100% Free Minecraft features showcase (Mod/Plugin support, DDoS Shield, Instant Chunks, 1-Click Installer, Multi-user SMP console).
- **Dot Pattern Ambient Backgrounds**: Radial-masked SVG dot matrix backgrounds for sleek luxury contrast.
- **Interactive Review Marquee**: Endless dynamic reviews ticker highlighting server creator testimonials.
- **Large Name Footer**: Responsive multi-column footer with brand watermark and social links.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Components**: [shadcn/ui](https://ui.shadcn.com/) patterns + [Lucide React](https://lucide.dev/) icons
- **Utilities**: `clsx`, `tailwind-merge`, `class-variance-authority`

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or pnpm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/xAyan55/KineticFree.git
cd KineticFree

# Install dependencies
npm install
```

### Development
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build
```bash
npm run build
```
The optimized production bundle will be generated in `dist/`.
